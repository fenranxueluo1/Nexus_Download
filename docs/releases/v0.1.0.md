# Nexus Download v0.1.0

Nexus Download 的首个公开版本。

一个基于 Flutter 的本地优先媒体解析与归档工具，支持哔哩哔哩、YouTube、X（Twitter）和抖音。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11 x64 | `NexusDownload-Windows-v0.1.0.zip` | 解压即用，内置 FFmpeg、yt-dlp、Deno |
| Android 7.0+ | `NexusDownload-Android-v0.1.0.apk` | 通用 APK，使用系统 MediaMuxer 合并 MP4/M4A |

## 主要功能

- B 站视频、番剧、课程、收藏夹、合集、系列、创作者投稿
- YouTube 单视频、Shorts 和播放列表
- X 公开视频帖子
- 抖音公开视频和 `v.douyin.com` 分享短链
- 分片下载、断点续传、并发任务、限速
- 自动检测系统代理和常见本机代理端口，也支持手动 HTTP/HTTPS 代理
- 视频/音频合并，字幕、弹幕、封面与 NFO 导出
- 路径模板、输出方案、任务日志和完成记录
- B 站扫码登录，Windows/macOS 支持 YouTube/X 应用内登录，抖音支持桌面和移动端登录

## 安装与运行

### Windows

1. 解压整个 `NexusDownload-Windows-v0.1.0.zip`。
2. 运行 `nexus_download.exe`。
3. 如果应用内登录窗口空白，运行 `redist/MicrosoftEdgeWebView2Setup.exe`。

包内已经包含 FFmpeg、yt-dlp、Deno、VC++ 运行库和 WebView2 安装引导，不需要额外安装 Flutter、Python 或下载器。

注意：当前 Windows 包未做代码签名，首次运行可能触发 SmartScreen 提示。请确认文件 SHA256 后再运行。

### Android

1. 安装 `NexusDownload-Android-v0.1.0.apk`。
2. 按系统提示允许安装未知来源应用。
3. 建议在设置中确认保存位置和代理。

当前 APK 使用 Android Debug 证书签名，适合测试和 GitHub 直接分发；后续如果要上架应用商店或做长期升级，需要改用固定的发布证书重新签名。

> 本次重新上传的 Android APK 已补齐 `INTERNET` 和 `ACCESS_NETWORK_STATE` 权限，Release 包可以正常联网。

## 平台说明

- **Windows**：功能完整，已验证构建和运行。
- **macOS**：需要 macOS 12+、Xcode/CocoaPods 和 FFmpeg；可使用仓库中的 `scripts/package_macos.sh` 构建，本次 Release 暂未附 macOS 包。
- **Linux**：可使用仓库中的 `scripts/package_linux.sh` 构建；需要 GTK3 等系统库，且没有应用内 WebView 登录。
- **Android/iOS**：不支持 yt-dlp/Deno，YouTube 使用纯 Dart 提取，部分视频可能失败；只支持合并为 MP4/M4A，不支持 MKV、MP3、FLAC、字幕嵌入或封面嵌入。

## 修复

- Android Release 补齐 `INTERNET` 和 `ACCESS_NETWORK_STATE` 权限，允许公开平台的 HTTP 媒体地址；请使用本次重新上传的 APK。

## 已知限制

- X 仅支持公开视频帖子，不包含私密、受保护或直播内容。
- 抖音图文作品不支持；被标记为 `base_charge_limit_source` 的付费/受限作品无法下载。
- YouTube 部分视频需要登录 Cookie、JS challenge 或代理；桌面端会自动下载 Deno。
- 移动端 YouTube 能力受限。
- Windows 包未签名；Android APK 为 Debug 签名。
- macOS/Linux 包需要在对应系统上构建，本次 Release 不提供。
